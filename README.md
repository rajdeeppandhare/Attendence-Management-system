## 🚀 Overview

The **Attendance Management System** is a web-based solution designed to simplify and automate attendance tracking for educational institutions. The project was developed as my **3rd Semester mini-project** during engineering college. It showcases skills in front-end web development, combining an intuitive UI with core attendance features suitable for classroom or training environments.

---

## 🌟 Features

- ✅ **Teacher & Student Interface:** Clean, role-based UI for marking and viewing attendance.
- 📊 **Attendance Analytics:** Visual summaries of students present/absent by date and class.
- ⏱ **Real-time Updates:** Record attendance quickly and accurately, reducing paperwork.
- 🔒 **Access Control:** Basic demo login to switch between “Teacher” and “Student” views.
- 📁 **Data Export:** Option to download attendance as CSV (demo or planned feature).
- ✨ **Responsive Design:** Works smoothly on laptops, tablets, and mobile devices.

   ```bash
   git clone https://github.com/rajdeeppandhare/Attendence-Management-system.git
   cd Attendence-Management-system
   ```
2. **Open `index.html` in your browser:**
   - No backend/server setup needed.
   - Explore both teacher and student demos.
